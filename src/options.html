L LingoLayer · 设置

基于 DeepSeek 的网页双语对照翻译。默认手动启用：点击扩展图标或按 Alt+T 翻译整页；选中文字后右键或按 Alt+S 只翻译选中内容。 打开操作演示页 →

API 设置

在 platform.deepseek.com 创建。密钥仅保存在本机浏览器中，不会上传到任何第三方。

默认 https://api.deepseek.com ，可改为兼容 OpenAI 协议的代理地址。

翻译场景推荐 deepseek-v4-flash，速度快、成本低。

翻译行为

源语言自动识别，任意语言都会被翻译为目标语言；已是目标语言的段落会自动跳过。

默认手动：不会在你没要求时消耗任何 token。若某些网站希望打开即翻译，选择「仅白名单」并把域名填进下方白名单。
