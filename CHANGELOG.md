# Changelog

All notable changes to LingoLayer are documented in this file.

## [1.0.2] - 2026-09-03

### Added

- Translate a selected page area without translating the entire page.
- Shopping summary card with product overview, price, delivery, returns, and highlights.
- Per-site terminology memory for consistent shopping terms.
- Translation feedback actions: use more natural wording, keep original, or skip text.
- Original-text tooltip when using Replace original mode.
- Store-ready logo, screenshots, and promotional tiles.

### Changed

- Expanded target-language choices, including a custom target language.
- Improved replacement-mode support for shopping menus, labels, and navigation.

## [1.0.1] - 2026-09-01

### Added

- Multilingual target language selection.
- Per-site Replace original mode for shopping pages.
