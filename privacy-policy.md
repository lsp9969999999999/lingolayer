# Deepread Privacy Policy

**Effective date:** 2026-09-01

Deepread is a browser extension that translates visible webpage text into a user-selected target language.

## Data processing

- Deepread reads webpage text only after the user starts translation or enables automatic translation for a site.
- Selected text is sent to the translation endpoint configured in the extension settings. The default endpoint is DeepSeek (`https://api.deepseek.com`).
- Deepread does not operate a user account, analytics system, advertising system, or remote tracking service.
- API keys are stored locally in the browser's extension storage and are not sent to the developer.
- Translation results may be cached locally when the cache option is enabled.
- Users can clear the local translation cache from the extension settings.

## User responsibility

Users should not translate confidential, personal, financial, medical, password, or other sensitive information unless they understand and accept the policies of the selected translation provider.

## Sharing

Deepread does not sell or share data with the developer. Webpage text and API requests are sent directly from the extension to the endpoint selected by the user. The selected provider may process data according to its own terms and privacy policy.

## Permissions

The extension requests access to webpage content so it can translate pages, local storage so it can save settings and cache results, scripting for user-triggered operation on supported pages, and context menus for translation commands.
