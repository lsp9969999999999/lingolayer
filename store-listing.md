# Chrome Web Store Listing

## Name

Deepread — Bilingual Web Translator

## Short description

Read the web in two languages with DeepSeek-powered translation while keeping the original text intact.

## Detailed description

Deepread adds inline translations below original webpage text for a focused bilingual reading experience.

Features:

- Translate full pages or selected text.
- Keep original text visible for easy comparison.
- Support dynamic pages, menus, navigation, and infinite-scroll content.
- Translate only visible content to reduce unnecessary requests.
- Cache repeated translations locally.
- Skip code blocks, commands, file names, and technical identifiers.
- Choose target language, translation style, font scale, and automatic-translation rules.
- Use your own DeepSeek API key and endpoint.

Deepread does not provide a translation service or API key. Users are responsible for their selected provider, API usage, and content sent for translation.

## Privacy disclosure summary

Deepread processes webpage text and sends it to the translation endpoint selected by the user. API keys and cached translations are stored locally in the browser. No developer analytics or advertising tracking is included.
