# 深译 Deepread

> 基于 DeepSeek 的网页双语对照翻译扩展（Chrome / Edge，Manifest V3）

**手动启用**：点扩展图标或按 `Alt+T` 才开始翻译当前网页。译文插在每段原文下方，**原文完整保留**，形成中外对照；再点一次恢复原文。也可以只翻译选中的一段文字。源语言自动识别（任意语言），目标语言默认中文。

## 功能

- **双语对照**：译文作为独立节点插在每段原文后面，原文一个字都不改，可随时一键恢复。
- **默认手动、绝不偷跑**：不主动翻译任何页面，不在你没要求时消耗 token。需要时也可为指定网站开启自动翻译。
- **任意语言 → 中文**：自动识别源语言；已经是目标语言的段落会被跳过。也可切换目标语言为繁體 / English / 日本語 / 한국어。
- **划词翻译**：选中任意文字 → 右键「翻译选中内容」或按 `Alt+S`，译文直接嵌到该段文字下方，呈现方式与整页翻译完全一致。
- **智能跳过代码**：代码块、命令行、文件名、标识符、版本号自动不翻译（见下方「技术文档场景」）。
- **智能分段**：按段落（p、li、td、h1–h6、blockquote 等）切分，行内元素（a、strong、em 等）合并进同一句，避免把一句话拆碎。
- **自动跳过**：script / style / pre / code / 输入框 / 隐藏元素 / .notranslate / 纯数字符号 / 纯链接。
- **按需翻译**：只翻译进入视口的内容，滚动到哪翻到哪，省钱省时间。
- **动态页面支持**：MutationObserver + SPA 路由监听，无限滚动、异步加载的新内容会自动补翻。
- **批量 + 并发 + 缓存**：多段合并成一次请求，并发可调，本地缓存命中不重复计费；失败自动重试、整批失败自动逐条降级、单段失败可点击重试。
- **克制的视觉**：译文默认为原文的 92% 字号；等待时只有一条 3px 高、延迟 0.6 秒才淡入的细占位条，接口快时完全无感。
- **阅读位置不跳动**：译文以视口顶部元素为锚点整批写入并自动补偿滚动，页面在翻译过程中不会把你正在读的那一行往下推。
- **内置演示页**：点扩展弹窗的「操作演示」，打开带引导步骤的示例页面，可直接在上面体验整页翻译、划词翻译、样式调节和代码跳过效果。
- **可调样式**：下划虚线 / 下划实线 / 浅色背景 / 左侧竖线 / 无装饰，译文字号可调（70%–130%）。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions/`。
2. 右上角打开 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择 **`deepread` 目录**（也就是含 `manifest.json` 的那一层，不是它里面的 `test/`）。
4. 首次安装会自动打开设置页，填入 **DeepSeek API Key**（在 <https://platform.deepseek.com/api_keys> 创建），点 **测试连接**，再点 **保存设置**。
5. 建议把扩展图标固定到工具栏（拼图图标 → 图钉）。

> 要加载的是 `deepread` 整个文件夹，不要选中 `manifest.json` 这个文件，也不要选 `deepread/test/`（那只是测试代码，没有 manifest，加载会报错）。
> `test/` 放在项目内不影响加载，Chrome 只读取 `manifest.json` 声明过的文件；日后打包上架时把 `test/` 排除即可。
> 开着开发者模式时把文件夹拖到 `chrome://extensions` 页面通常也能装上；如果拖拽没反应，用上面的按钮最稳妥。改完代码后回到该页面点扩展卡片上的**刷新**按钮即可生效。

## 使用

| 操作 | 说明 |
| --- | --- |
| 翻译当前页 | 点扩展图标 → **翻译此页面**；再点变成 **恢复原文** |
| 只翻译选中内容 | 选中文字 → 右键 **深译：翻译选中内容**，或按 `Alt + S`；译文嵌在该段下方 |
| 操作演示 | 扩展弹窗 → **操作演示**，打开内置示例页边看边试 |
| 快捷键 | `Alt + T` 整页翻译 / 恢复；`Alt + S` 翻译选中内容 |
| 右键菜单 | 选中文字时显示「翻译选中内容」；未选中时显示「翻译此页面 / 恢复原文」 |
| 本站自动翻译 | 弹窗里的开关：打开后该网站以后自动翻译（自动切到白名单模式），其他网站仍保持手动 |
| 高级设置 | 弹窗 → 高级设置：模型、并发、批量大小、缓存、样式等 |

扩展图标上的角标显示当前页已翻译的段落数。

## 三种启用模式

| 模式 | 行为 |
| --- | --- |
| **手动启用（默认）** | 任何网站都不自动翻译，点图标或 `Alt+T` 才翻 |
| 仅白名单自动 | 只有白名单里的域名打开即自动翻译（含子域名） |
| 全部网站自动 | 除黑名单外所有网站打开即自动翻译 |
## 技术文档场景：为什么代码不会被翻译

技术文档、代码仓库里混杂着大量不该翻译的内容。开启「智能跳过代码」（默认开启）后，以下内容会被自动识别并跳过：

| 类型 | 例子 | 识别方式 |
| --- | --- | --- |
| 代码块 / 终端 | `<pre>`、`<code>`、`.highlight`、`.hljs`、`.token`、CodeMirror、Monaco 等 | 标签 + class/id 特征 |
| 等宽字体内容 | GitHub 文件名、命令行输出、行内代码 | **计算样式里的字体是等宽** —— 这是最通用的信号，无需为每个网站单独写规则 |
| 命令行 | `npm install`、`$ git clone …`、`docker run …` | 提示符开头或常见命令开头 |
| 文件名 / 路径 | `README.md`、`src/index.ts`、`package.json` | 单 token + 扩展名 / 路径分隔符 |
| 标识符 | `getUserProfile`、`MAX_RETRY_COUNT`、`--verbose` | camelCase / CONST_CASE / 命令行参数 |
| 工程目录名 | `src`、`dist`、`node_modules` | 常见目录名词表 |
| 其他 | `v2.14.0`、`#4D6BFE`、符号密度过高的行 | 版本号 / 颜色值 / 符号密度 |

正常英文句子即使包含 `config`、`code` 这类词也**不会**被误跳过。若某个页面确实需要翻译代码注释，可在设置页关掉这个开关。

## 性能与视觉

翻译一整页时最影响体验的是「慢」和「晃」，这两点都做了针对性处理：

- **首批立即发出**：第一批不等合批延迟直接请求，第一屏译文最快出现；后续才按 150ms 小幅合批以减少请求数。
- **更高并发**：默认并发 5、每批 10 段，可在设置页调整（遇到 429 限流就调低）。
- **提前预取**：视口外 900px 的内容提前开始翻译，滚动到时译文往往已就位。
- **不跳动**：每批结果在同一帧写入，写入前以视口顶部元素为锚点测量位置，写入后自动补偿滚动量；译文节点同时设置 `overflow-anchor: none`，避免与浏览器自身的滚动锚定打架。
- **占位极轻**：等待中的段落只占 3px 高的细条，且延迟 0.6 秒才淡入，接口响应快时你根本不会看到它。

## 设置说明

- **模型**：`deepseek-v4-flash`（推荐，快且便宜）或 `deepseek-v4-pro`（质量更高）。
- **自动翻译范围**：默认「手动启用」。只有你明确改成白名单 / 全站模式，才会出现自动翻译。
- **智能跳过代码**：默认开启。技术文档、代码仓库建议保持开启。
- **译文字号**：默认 92%（比原文小一号）。可在设置页 70%–130% 调整。
- **深度思考模式**：默认关闭。翻译不需要思维链，关闭后更快更省；开启会明显变慢变贵。
- **仅翻译进入视口的内容**：默认开启，强烈建议保留，长页面能省下大量 token。
- **每次请求段落数 / 最大字符数**：越大越省请求数，但单次延迟更高；默认 12 段 / 2400 字符。
- **并发请求数**：默认 3，网络好可调到 5–6，遇到 429 限流请调低。
- **本地翻译缓存**：相同原文不重复请求，最多缓存 3000 条，可在设置页清空。

## 隐私

- API Key 只保存在浏览器本地（`chrome.storage.local`），不上传任何第三方服务器。
- 网页文本只发送给你自己配置的 DeepSeek API 地址，扩展本身不做任何统计或上报。

## 项目结构

```
deepread/               项目根目录（加载扩展时选这一层）
├── manifest.json       扩展清单（Manifest V3）
├── src/background.js   Service Worker：API 调用、批量调度、并发/重试/缓存、菜单与快捷键
├── src/content.js      内容脚本：段落切分、按需触发、译文注入、还原
├── src/content.css     译文样式（5 种主题 + 加载/错误态）
├── src/popup.*         工具栏弹窗：开关、本站设置、目标语言、样式
├── src/options.*       设置页
├── src/demo.*          操作演示 / 上手引导页：API Key、模型、范围、性能、缓存
├── icons/              扩展图标
└── test/               Node 测试（jsdom + 打桩 fetch，不参与扩展加载）
```

## 常见问题

**页面没有翻译？** 检查设置页是否填了 API Key 并测试连接成功；`chrome://`、Chrome 应用商店等系统页面不允许扩展注入。刚安装时已打开的标签页需要刷新一次。

**显示翻译失败（点击重试）？** 鼠标悬停可看具体错误：401 是 Key 无效，402 是余额不足，429 是请求过快（把并发调低）。点击该提示可单独重试这一段。

**想让某个网站不翻译？** 在该网站点开扩展弹窗，关掉 “本站自动翻译”；或在设置页黑名单里按行添加域名。
