LingoLayer Privacy Policy

Effective date: 2026-09-01

LingoLayer is a browser extension that translates visible webpage text into a user-selected target language.

Data processing

  • LingoLayer reads webpage text only after the user starts translation or enables automatic translation for a site.
  • Selected text is sent to the translation endpoint configured in the extension settings. The default endpoint is DeepSeek.
  • LingoLayer does not operate a user account, analytics system, advertising system, or remote tracking service.
  • API keys and cached translations are stored locally in the browser.

User responsibility

Users should not translate confidential, personal, financial, medical, password, or other sensitive information unless they understand and accept the selected provider's policies.

Sharing

LingoLayer does not sell or share data with the developer. Webpage text and API requests are sent directly from the extension to the endpoint selected by the user.

Permissions

The extension requests webpage access for translation, local storage for settings and cache, scripting for user-triggered operation, and context menus for translation commands.
